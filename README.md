# mp4-to-webp

mp4をアップロードして、指定サイズ（初期値500KB）以下のanimated webpに変換するツール。

公開URL: https://squad-customersupport.github.io/mp4-to-webp/

## やっていること

変換はすべてブラウザ内で完結する。動画ファイルはサーバーに送信されない。だからサーバー側のコードが存在せず、GitHub Pagesで公開できる。

横幅350px・画質0.9・12fpsで書き出してみて、指定サイズを超えていたら以下の順に1段ずつ下げ、最初に収まった時点で止める。

1. fps（12 → 10 → 8 → 6 → 5 → 4 → 3 → 2）
2. 画質（0.85 → 0.8 → ... → 0.3）
3. 横幅（320 → 288 → ... → 160）

画質を優先したいので、fpsから先に落とす設計にしている。fpsを落としすぎたくない場合は、切り出し範囲（開始秒・終了秒）を狭めて尺そのものを短くする。

animated webpの組み立て（VP8Xチャンク、ANIMチャンク、フレームごとのANMFチャンク）は外部ライブラリを使わず自前でRIFFを書いている。ここが一番壊れやすい箇所なので、再生できない動画が出たらまずここを疑う。

Chrome専用。`OffscreenCanvas.convertToBlob` の webp 出力に依存している。

## ファイル

- `index.html` — これ1枚がツールの全部。単体でブラウザに開いても動く

## 直しかた

1. GitHubで `index.html` を開き、鉛筆アイコンから編集する
2. Commit changes を押す
3. 1分ほどでGitHub Pagesに反映される

ローカルで直したい場合は、ファイルをダウンロードしてブラウザで開けばそのまま動作確認できる。サーバーもビルドも不要。
